# STRATUM

## Platform
Responsive web marketing concept.

## Brief
User requested a Palantir-inspired website adapted to heavy industries, with Cognite as a sector reference, real stock imagery, a public repository, and a prompt for another agent to extract its design into a skill.

## Assumptions for this version
STRATUM is an invented brand. Audience: industrial operations, maintenance, and digital transformation leaders. No actual product capabilities, customers, ROI claims, or service commitments are asserted. Demo data is synthetic and review state lasts only for the current page session.

## Stack
Plain HTML, CSS, and JavaScript, selected to make the design easy to inspect and reuse. No build or package installation required. Static files in dist/.

## Brand commitments
Palantir-inspired cinematic photography and editorial scale; Cognite-inspired industrial context. Original copy, visual identity, and implementation. No copied logos, proprietary screenshots, or testimonials.

## User refinement
Use the supplied Palantir screenshot’s topic tabs and oversized photographic panels, mixed with Mercury.com design and a purple palette. This supersedes the initial green/charcoal direction.
